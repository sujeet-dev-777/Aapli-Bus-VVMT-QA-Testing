# Aapli Bus VVMT – Mobile Application Testing

## Project Overview

A manual testing project performed on the Aapli Bus VVMT mobile application
to validate functionality, usability, localization, GPS/location behavior,
network conditions, bus search, bus tracking, bus stops, games and other
available application modules.

## Testing Types

- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Exploratory Testing
- Negative Testing
- UI/UX Testing
- Localization Testing
- GPS/Location Testing
- Network Testing
- Compatibility Testing
- Performance Observation

## Modules Tested

- Application Launch
- Navigation
- Announcements
- Bus Search
- Bus Tracking
- Bus Stops
- Map
- Location/GPS
- Language
- Jobs
- Games
- Network/Offline Behavior
